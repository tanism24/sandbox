# Hello, World — Powered by AI 🚀

A tiny, self-contained demo app to show friends how powerful AI is. The entire
thing — layout, animations, and code — was generated by an AI assistant.

## How to run it

No installs, no build step, no internet required.

1. Open the `hello-world` folder.
2. **Double-click `index.html`** — it opens in your default browser.

That's it.

## What to show off

- **Animated headline** that types itself out and cycles through phrases.
- **"Say hello in another language"** — cycles through 10 languages.
- **"Surprise me"** — fires a confetti burst.
- A drifting starfield runs the whole time on an HTML canvas.

Everything lives in a single `index.html` file (~250 lines) with zero
dependencies — a nice talking point for just how fast AI can produce a
polished, working app.

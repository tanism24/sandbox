# Hello, World — Powered by AI 🚀

A tiny, self-contained demo app to show friends how powerful AI is. The entire
thing — layout, animations, and code — was generated by an AI assistant.

## 🌐 Live demo (open on any phone)

Once GitHub Pages is enabled (see below), the app is live at:

**https://tanism24.github.io/sandbox/**

Just send that link to your friends — it opens instantly in any phone browser.

## Enable GitHub Pages (one-time, ~30 seconds on your phone)

1. Open the repo on GitHub → **Settings** → **Pages** (under "Code and automation").
2. Under **Build and deployment → Source**, choose **Deploy from a branch**.
3. Set **Branch** to `claude/hello-world-demo-app-iuyc66`, folder `/ (root)`, then **Save**.
4. Wait ~1 minute, then open **https://tanism24.github.io/sandbox/**.

## Run it locally instead

No installs, no build step, no internet required — just **double-click `index.html`**.

## What to show off

- **Animated headline** that types itself out and cycles through phrases.
- **"Say hello in another language"** — cycles through 10 languages.
- **"Surprise me"** — fires a confetti burst.
- A drifting starfield runs the whole time on an HTML canvas.

Everything lives in a single `index.html` file with zero dependencies — a nice
talking point for just how fast AI can produce a polished, working app.
